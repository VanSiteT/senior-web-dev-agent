⚡ Cara Install (Pilih salah satu)

Cara 1 — Paling recommended RECOMMENDED

Jalankan di terminal (root project):

curl -o .cursorrules https://raw.githubusercontent.com/VanSiteT/senior-web-dev-agent/main/.cursorrules

Cara 2 — Download manual

1. Klik tombol Download File di atas

2. Rename file dari cursorrules.txt menjadi .cursorrules

3. Pindahkan ke root project kamu

Setelah file .cursorrules ada di root project, Cursor akan otomatis membacanya.
